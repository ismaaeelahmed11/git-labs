# Git Labs

Hands-on Git practice repository — used for learning version control commands, workflows, and troubleshooting in a safe environment.

---

## What This Repo Contains

This is my sandbox for Git. I use it to practice concepts before applying them in my main portfolio. Expect messy commits, experimental branches, and deliberate mistakes.

## Topics Practiced

- Initialising repositories and making first commits
- Working directory, staging area, and repository workflow
- Branching and merging strategies
- Rebasing vs merging
- Git stash and popping changes
- Resetting, reverting, and undoing mistakes
- Cherry-picking specific commits
- Amending commits
- SSH key setup and remote repository management
- Pre-commit hooks for automated checks
- .gitignore for keeping repos clean

## Key Commands Practiced

git init
git add
git commit
git push / git pull
git branch / git checkout
git merge / git rebase
git stash / git stash pop
git reset / git revert
git cherry-pick
git commit --amend
git reflog

## Why This Repo Exists

Version control is a non-negotiable skill in DevOps. This repo is proof of deliberate practice — not just knowing the commands, but understanding when and why to use them.
